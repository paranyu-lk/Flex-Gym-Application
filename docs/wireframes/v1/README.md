# FLEX — ชุดอ้างอิง UI เวอร์ชันแรก

วันที่เก็บสำเนา: 14 ตุลาคม 2569 (2026-10-14) · เขตเวลา Asia/Bangkok

โฟลเดอร์นี้เก็บสำเนาต้นฉบับ wireframe ธีมดำล่าสุดและสเปก MVP เวอร์ชันแรก เพื่อใช้อ้างอิงระหว่างพัฒนาแอปด้วย Flutter โดย wireframe เป็นต้นแบบ HTML สำหรับทดลองหน้าตาและการใช้งาน

## ไฟล์ในชุดนี้

- `index.html`: wireframe ที่ส่งออกสำหรับเปิดแยกในเบราว์เซอร์ เปิดไฟล์นี้เพื่อทดลองใช้งานได้โดยไม่ต้อง build แอป Flutter
- `source.html`: สำเนาต้นฉบับ wireframe ที่เคยแสดงในแชต เก็บไว้เป็นต้นฉบับสำหรับแก้ไข หากเปิดไฟล์นี้เพียงลำพังนอกแชต จะไม่มีระบบไอคอนและสภาพแวดล้อมที่ตัวแสดงผลจัดเตรียมให้
- `MVP_SPEC.md`: สำเนาข้อกำหนด MVP เวอร์ชันแรก
- `DATA_MODEL.md`: สำเนาข้อเสนอโครงสร้างข้อมูลเริ่มต้น
- `manifest.json`: ข้อมูลชุดสำรอง ขนาดไฟล์ และค่า SHA-256 สำหรับตรวจสอบความตรงกันของไฟล์

## สิ่งที่เก็บไว้

หน้าวันนี้ (Today), โปรแกรม (Programs), ตาราง (Schedule), ประวัติ (History), การแก้ไขโปรแกรมต้นแบบ, การเลือกท่า, เป้าหมายรายเซต, การตั้งเวลาพัก, รูปแบบน้ำหนักตัวและน้ำหนักเพิ่ม, การปัดซ้ายเพื่อเผยปุ่มลบ, การเลิกทำ, การยืนยันเซตสำเร็จ และ UI นับเวลาพัก โดย `index.html` รวมระบบแสดงผลและไอคอนที่จำเป็นไว้แล้ว

สำเนานี้เก็บโค้ด UI และข้อมูลสาธิตเริ่มต้น ไม่ได้เก็บสถานะการทดลองที่ยังอยู่เฉพาะในแชต และข้อมูลสาธิตไม่ใช่ประวัติการฝึกจริง ตัวแสดงผลที่ส่งออกอาจจดจำการทดลองครั้งถัดไปไว้ในพื้นที่จัดเก็บของเบราว์เซอร์เมื่อระบบรองรับ หากต้องการดูข้อมูลเริ่มต้น ให้เปิดด้วยโปรไฟล์เบราว์เซอร์ใหม่

## ข้อมูลอ้างอิงสำหรับพัฒนา

- คงข้อความเดิมของ wireframe ไว้ รวมถึงข้อความภาษาไทย ส่วนแอป Flutter ให้ใช้ข้อความและ label ภาษาอังกฤษเป็นหลักตามที่ตกลงกันภายหลัง
- สีพื้นหลัง: `#090909`; พื้นการ์ด: `#171717`; พื้นผิวที่ยกขึ้น: `#232323`
- สีเส้นขอบ: `#343434`; ตัวอักษรหลัก: `#F5F5F3`; ตัวอักษรรอง: `#A5A5A5`
- รัศมีมุมเริ่มต้น: 12 พิกเซล; ความกว้างกรอบโทรศัพท์ต้นแบบ: ไม่เกิน 390 พิกเซล
- ปัดแถวเซตไปทางซ้ายเพื่อเผยปุ่มลบ โดยเว้นช่องว่างจากปุ่มติ๊กสำเร็จ และไม่เพิ่มเครื่องหมาย `<` เพื่อบอกการปัดบนแถวเซต
- ค่าข้างต้นเป็นข้อมูลอ้างอิงจากต้นแบบ เมื่อพัฒนาด้วย Flutter ต้องคำนึงถึงพื้นที่ปลอดภัยของหน้าจอ (safe area), การขยายตัวอักษร, แป้นพิมพ์ และพฤติกรรมของแต่ละแพลตฟอร์มด้วย
- ตัวจับเวลาและเสียงในเบราว์เซอร์เป็นการสาธิต UI ส่วนการแจ้งเตือนขณะสลับแอปหรือล็อกหน้าจอบน Android/iOS ยังต้องพัฒนาให้รองรับระบบปฏิบัติการและทดสอบบนอุปกรณ์จริง

## การตรวจสอบที่ทำแล้ว

เปิด `index.html` ในเบราว์เซอร์แล้ว พบว่าหน้า Programs แสดงผลพร้อมไอคอน และเปิดหน้าแก้ไข Upper Body ได้ โดยมีการตั้งเวลาพักและช่องกรอกน้ำหนักกับจำนวนครั้งแยกแต่ละเซต ตรวจสอบแล้วว่าไฟล์ที่ส่งออกมีต้นฉบับ wireframe ตรงกับสำเนาที่เก็บไว้

การตรวจสอบชุดสำรองครั้งนี้ยังไม่ได้ทดสอบทุกปฏิสัมพันธ์หรือการแจ้งเตือนบนมือถือซ้ำทั้งหมด

## การจัดการเวอร์ชันและเอกสารหลัก

ใช้โฟลเดอร์นี้เป็นชุดอ้างอิง UI v1 หากปรับแบบในอนาคต ให้สร้างโฟลเดอร์เวอร์ชันใหม่แทนการเขียนทับชุดนี้ ส่วนเอกสารสเปกและโครงสร้างข้อมูลที่ใช้พัฒนาต่อ ให้ยึดไฟล์ในโฟลเดอร์ `docs/` เป็นหลัก และอัปเดตไฟล์เหล่านั้นตามแอปปัจจุบัน

ควรเก็บชุดอ้างอิงนี้ไว้ในประวัติ Git ของโปรเจกต์เมื่อบันทึกการเปลี่ยนแปลง ทั้งนี้ การสร้างชุดสำรองครั้งนี้ยังไม่ได้สร้าง Git commit
