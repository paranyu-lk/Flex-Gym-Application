# FLEX — สเปกเวอร์ชันแรก

วันที่: 2026-10-14 · สถานะ: สรุปจาก Wireframe ที่ผู้ใช้พอใจแล้ว และข้อเสนอสำหรับเริ่มพัฒนา

## 1. เป้าหมายและแพลตฟอร์ม

แอปสำหรับสร้างโปรแกรมฝึกส่วนตัว จัดวันและเวลา บันทึกผลการฝึกแยกแต่ละเซต และเปิดประวัติย้อนหลัง พัฒนาด้วย Flutter สำหรับ Android และ iOS

แนวทางเริ่มต้น: เก็บข้อมูลในเครื่องและใช้งานหลักได้แบบออฟไลน์ ยังไม่ต้องมีบัญชีผู้ใช้หรือระบบซิงก์

## 2. รูปแบบ UI

- ธีมดำ ให้ความรู้สึกหนักแน่น ใช้พื้นดำ/เทาเข้ม ตัวอักษรตัดกับพื้นหลังชัดเจน
- ปุ่มหลักสีสว่าง ปุ่มลบใช้สีที่สื่อถึงการลบ
- แถบเมนูหลัก 4 แท็บ: **วันนี้ / โปรแกรม / ตาราง / ประวัติ**
- หน้าจัด Preset และหน้าฝึกใช้แถวเซตรูปแบบเดียวกัน โดยเลือกดูทีละท่า
- แถวเซตไม่แสดงเครื่องหมาย `<` และไม่แสดงปุ่มลบค้างไว้
- ปัดแถวไปทางซ้ายเพื่อเผยปุ่มลบ ปัดขวาหรือแตะบริเวณอื่นเพื่อปิด เปิดได้ทีละแถว
- เมื่อเผยปุ่มลบ ต้องมีช่องว่างจากปุ่มติ๊กสำเร็จ; Wireframe ปัจจุบันเว้น 10 พิกเซล
- แยกการปัดแนวนอนจากการเลื่อนหน้าแนวตั้ง และไม่ให้การปัดกลายเป็นการติ๊กสำเร็จ
- มีวิธีเปิดตัวเลือกลบที่ใช้กับแป้นพิมพ์/เครื่องมือช่วยการเข้าถึงได้ด้วย

## 3. หน้าจอและพฤติกรรม

### 3.1 วันนี้

- แสดงวันที่จริงและรายการฝึกที่ลงตารางไว้สำหรับวันนั้น
- แสดงชื่อโปรแกรม เวลา จำนวนท่า จำนวนเซต และเป้าหมายรายเซต
- เริ่มฝึกหรือกลับไปฝึกต่อจาก Session ที่ค้างไว้
- หากไม่มีรายการ ให้เลือก Preset ลงตารางได้
- สถานะฝึกแล้วต้องอ้างอิงรายการในตารางที่เกี่ยวข้อง ไม่ตัดสินจากการมีประวัติใด ๆ ในวันเดียวกัน

### 3.2 โปรแกรมฝึก / Preset

- แสดงโปรแกรมที่บันทึกไว้ พร้อมชื่อ จำนวนท่า และจำนวนเซตรวม
- สร้าง Preset ใหม่ ตั้งชื่อ เลือกท่าจากคลัง และนำท่าออกจากโปรแกรมได้
- แก้ไข Preset เดิมและใช้ Preset เดียวลงตารางซ้ำในวันต่าง ๆ ได้
- เลือกดูทีละท่า ในแต่ละท่ามีแถวสำหรับทุกเซต
- แต่ละเซตกรอกจำนวนครั้งและน้ำหนักแยกกัน ไม่ใช้ค่าชุดเดียวบังคับทุกเซต
- เพิ่มเซต ปัดลบเซต และเลิกทำการลบล่าสุดได้
- ตั้งเวลาพักต่อเซตแยกตามท่า เวอร์ชันแรกใช้เวลาพักเดียวกันสำหรับทุกเซตภายในท่านั้น
- หน้าจัดโปรแกรมไม่มีการติ๊กว่าเซตฝึกสำเร็จ และไม่เริ่มจับเวลาพัก
- บันทึก Preset ก่อน แล้วค่อยใช้ปุ่ม **ลงตาราง** เพื่อเลือกวันและเวลา

ตัวอย่าง Preset:

| ท่า | เซต | น้ำหนัก | จำนวนครั้ง | เวลาพักของท่า |
|---|---:|---:|---:|---:|
| Bench Press | 1 | 40 กก. | 12 | 90 วินาที |
| Bench Press | 2 | 45 กก. | 10 | 90 วินาที |
| Bench Press | 3 | 50 กก. | 8 | 90 วินาที |
| Push-up | 1 | น้ำหนักตัว | 15 | 60 วินาที |
| Push-up | 2 | น้ำหนักตัว | 12 | 60 วินาที |

### 3.3 รูปแบบน้ำหนักของท่า

| รูปแบบ | คอลัมน์ที่แสดง | ความหมายของน้ำหนักที่กรอก |
|---|---|---|
| ใช้น้ำหนัก เช่น Bench Press | เซต / กก. / ครั้ง | น้ำหนักอุปกรณ์ที่ใช้ตามวิธีบันทึกของท่านั้น |
| น้ำหนักตัว เช่น Push-up | เซต / ครั้ง | ไม่กรอกน้ำหนัก และไม่บันทึกว่าเป็น 0 กก. |
| น้ำหนักตัว + น้ำหนักเพิ่ม | เซต / กก. เพิ่ม / ครั้ง | เฉพาะน้ำหนักที่ถ่วงเพิ่ม ไม่รวมมวลร่างกาย |

- คลังท่าระบุรูปแบบที่รองรับและค่าเริ่มต้นของแต่ละท่า
- ท่าน้ำหนักตัวที่รองรับการถ่วงเพิ่มสามารถสลับระหว่างสองรูปแบบนั้นได้
- ใช้รูปแบบเดียวกันตลอดทุกเซตของท่าใน Preset นั้น
- หน้าฝึกและประวัติต้องรักษาความหมายของรูปแบบที่เลือกไว้

### 3.4 ตารางฝึก

- เลือกวันที่ ดูรายการฝึก และเพิ่มหรือแก้วันเวลาได้
- เลือก Preset พร้อมตรวจเป้าหมายทุกเซตก่อนบันทึก
- เมื่อลงตาราง ให้เก็บ Snapshot ของชื่อโปรแกรม ท่า รูปแบบน้ำหนัก เป้าหมายรายเซต และเวลาพัก
- การแก้ Preset ภายหลังไม่เปลี่ยนรายการที่ลงตารางไว้แล้ว
- หากต้องการใช้ Preset เวอร์ชันใหม่กับรายการเดิม ให้เลือกโปรแกรมใหม่อย่างชัดเจน
- หากมีรายการในวันเดียวกัน ต้องแสดงให้เห็นชัดว่าเป็นการเพิ่มรายการหรือแก้รายการใด

ข้อเสนอสำหรับแอปจริง: รองรับหลายรายการต่อวัน แต่ละรายการมี ID และเวลาแยกกัน ข้อจำกัดหนึ่งรายการต่อวันในต้นแบบไม่ใช่ข้อกำหนดถาวร

### 3.5 บันทึกการฝึก

- เริ่ม Session จาก Snapshot ของรายการในตาราง
- แสดงท่าทีละท่า พร้อมแถวเซตและคอลัมน์ตามรูปแบบน้ำหนัก
- เติมค่าเริ่มต้นจากเป้าหมายรายเซต และให้ปรับเป็นผลที่ทำจริงได้
- ติ๊กสำเร็จเพื่อยืนยันผลของเซตนั้น หลังยืนยันสามารถยกเลิกเครื่องหมายเพื่อแก้ไขได้
- เพิ่ม/ปัดลบเซตจริงได้ โดยไม่เปลี่ยน Preset หรือตารางต้นฉบับ
- มี “เลิกทำ” สำหรับการลบเซตล่าสุด คืนค่าและตำแหน่งเดิม
- พักการฝึกไว้แล้วกลับมาต่อได้ โดยข้อมูลที่กรอกไม่หาย
- จบและบันทึกได้แม้ฝึกไม่ครบ เมื่อมีอย่างน้อยหนึ่งเซตสำเร็จ
- ประวัติแสดงเฉพาะผลเซตที่ยืนยันแล้ว พร้อมบอกว่าฝึกครบหรือฝึกบางส่วน

### 3.6 เวลาพักและการแจ้งเตือน

- ติ๊กเซตสำเร็จแล้วเริ่มนับถอยหลังอัตโนมัติ ตามเวลาพักของท่านั้น
- ตั้งเป็น 0 วินาทีเพื่อไม่จับเวลาพัก
- แสดงชื่อท่าและเซตที่ทำให้เริ่มพัก พร้อมเวลาที่เหลือและปุ่มข้ามพัก
- เมื่อครบเวลา แสดง **“พักครบแล้ว”** และแจ้งเตือนด้วยเสียงเมื่อผู้ใช้เปิดเสียงและระบบอนุญาต
- หากติ๊กเซตใหม่ขณะที่กำลังพัก ให้ยกเลิกตัวจับเวลาเดิมและเริ่มจากเซตล่าสุด
- ยกเลิกเครื่องหมายหรือลบเซตต้นทาง ให้ยกเลิกตัวจับเวลาของเซตนั้น ไม่กระทบตัวจับเวลาของเซตอื่น
- สลับท่า กลับหน้าวันนี้ หรือพัก Session ไว้ ไม่ทำให้เวลาพักเริ่มใหม่
- จบ Session หรือกดข้ามพัก ต้องยกเลิกการเตือนที่ยังค้างอยู่
- เวอร์ชันจริงต้องทดสอบการแจ้งเตือนเมื่อสลับแอปและล็อกหน้าจอบน Android/iOS
- หากไม่อนุญาตการแจ้งเตือนหรือเสียง ยังต้องแสดงสถานะหมดเวลาในแอป

### 3.7 ประวัติ

- แสดงรายการฝึกตามวัน เปิดรายละเอียดแต่ละครั้งได้
- แสดงชื่อโปรแกรม ณ ตอนฝึก ท่าที่ทำจริง และผลแต่ละเซต
- แยกการใช้น้ำหนักกับน้ำหนักตัวให้ถูกต้อง รวมถึงน้ำหนักที่ถ่วงเพิ่ม
- การแก้ Preset หรือรายการในตารางต้องไม่เปลี่ยนประวัติย้อนหลัง
- เวอร์ชันแรกเน้นเปิดดูประวัติ ยังไม่เพิ่มขั้นตอนแก้ไขประวัติที่จบแล้ว

## 4. กฎข้อมูลและสถานะที่ต้องรองรับ

- ชื่อโปรแกรมต้องไม่ว่าง และมีอย่างน้อยหนึ่งท่าก่อนบันทึก
- แต่ละท่ามีอย่างน้อยหนึ่งเซต; เซตสุดท้ายลบไม่ได้ ต้องนำทั้งท่าออกแทน
- จำนวนครั้งเป็นจำนวนเต็มบวก น้ำหนักไม่ติดลบ และเวลาพักเป็นวินาทีที่ไม่ติดลบ
- น้ำหนักตัวใช้ค่าน้ำหนักว่าง (`null`) ในผลการฝึก ไม่ใช้เลข 0 แทน
- เก็บข้อมูลระหว่างกรอกโดยไม่ทำให้ช่องที่กำลังพิมพ์เสียโฟกัส
- รองรับสถานะยังไม่มีโปรแกรม ยังไม่มีตาราง ยังไม่มีประวัติ กรอกไม่ครบ และบันทึกข้อมูลล้มเหลว
- การเริ่มใหม่กับการกลับไป Session เดิมต้องชัดเจน ป้องกันการสร้างประวัติซ้ำจากการกดปุ่มซ้ำ
- การเริ่มโปรแกรมใหม่ขณะมี Session ค้าง ต้องมีทางเลือกให้จัดการ Session เดิมโดยข้อมูลไม่หาย

## 5. เกณฑ์ตรวจรับหลัก

1. สร้าง Preset ที่มี 40×12, 45×10 และ 50×8 ในท่าเดียวกัน แล้วเปิดใหม่ยังได้ค่าเดิม
2. เพิ่ม Push-up ที่แต่ละเซตมีจำนวนครั้งต่างกันได้ โดยไม่มีช่องกิโลกรัม
3. สลับ Push-up เป็นถ่วงน้ำหนักเพิ่มแล้วแสดงคอลัมน์น้ำหนักเพิ่มได้อย่างถูกต้อง
4. ลง Preset ในตารางและเริ่มฝึกแล้วได้เป้าหมายรายเซตตรงกันทุกค่า
5. แก้ Preset หลังลงตารางแล้ว รายการเดิมและประวัติไม่เปลี่ยน
6. ปัดซ้ายเผยปุ่มลบ ปัดขวาปิดได้ ไม่มีเครื่องหมาย `<` และปุ่มลบไม่ติดปุ่มติ๊ก
7. ลบเซตแล้วเลิกทำได้ โดยค่าน้ำหนัก จำนวนครั้ง และตำแหน่งกลับมาครบ
8. ติ๊กสำเร็จแล้วเริ่มพักอัตโนมัติ เมื่อหมดเวลาแจ้งเพียงครั้งเดียว และข้ามพักแล้วไม่เตือนซ้ำ
9. กลับเข้าหน้าฝึกหลังพักไว้หรือเปิดแอปใหม่ ข้อมูลรายเซตและเวลาพักยังถูกต้อง
10. จบการฝึกบางส่วนแล้วประวัติแสดงผลที่ยืนยันจริง พร้อมแยกน้ำหนักตัวจาก 0 กก.
11. การฝึกครบของรายการหนึ่งไม่ทำให้รายการอื่นในวันเดียวกันถูกระบุว่าฝึกแล้ว
12. เส้นทางหลักใช้งานออฟไลน์ได้ และทดสอบผ่านทั้ง Android/iOS

## 6. งานที่ยังไม่รวมในเวอร์ชันแรก

บัญชีผู้ใช้และ Cloud Sync, การแชร์โปรแกรม, โปรแกรมฝึกซ้ำตามกฎอัตโนมัติ, กราฟความก้าวหน้า, การเชื่อมอุปกรณ์/ข้อมูลสุขภาพ, AI สร้างโปรแกรม, การติดตามอาหาร และท่าที่วัดด้วยเวลา/ระยะทางแทนจำนวนครั้ง

ข้อเสนอฐานข้อมูลและโครงสร้างโค้ดอยู่ใน [DATA_MODEL.md](DATA_MODEL.md) ไม่ควรนำเพดานจำนวนท่า/เซตหรือช่วงวันที่สาธิตของ Wireframe ไปใช้เป็นข้อจำกัดผลิตภัณฑ์โดยอัตโนมัติ
