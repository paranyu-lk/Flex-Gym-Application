# FLEX Application — สเปกและโครงสร้างข้อมูล

อัปเดต: 14 ตุลาคม 2569 (2026-10-14)

แอป Flutter สำหรับ Android และ iOS เพื่อสร้างโปรแกรมออกกำลังกายแบบ Preset นำลงตาราง บันทึกผลรายเซต และดูประวัติ โดยใช้ Wireframe ธีมดำที่ออกแบบร่วมกันเป็นต้นแบบ

## เอกสาร

- [MVP_SPEC.md](MVP_SPEC.md): หน้าจอ ฟีเจอร์ พฤติกรรม และเกณฑ์ตรวจรับเวอร์ชันแรก
- [DATA_MODEL.md](DATA_MODEL.md): แบบจำลองข้อมูล ความสัมพันธ์ ตัวอย่าง Snapshot และกฎความถูกต้องของข้อมูล

## เส้นทางใช้งานหลัก

สร้าง Preset → เลือกท่า → ตั้งน้ำหนัก/จำนวนครั้งแยกแต่ละเซตและเวลาพัก → บันทึกโปรแกรม → เลือกวันและเวลา → เริ่มฝึก → บันทึกผลจริง → ดูประวัติ

## หลักสำคัญ

1. เป้าหมายใน Preset และผลการฝึกจริงเป็นข้อมูลคนละชุด
2. ตารางฝึกเก็บสำเนาของโปรแกรม ณ วันที่เลือก เพื่อให้การแก้ Preset ไม่เปลี่ยนรายการเดิม
3. แต่ละเซตตั้งน้ำหนักและจำนวนครั้งต่างกันได้
4. ท่าน้ำหนักตัวซ่อนช่องกิโลกรัม; หากเลือกถ่วงน้ำหนักเพิ่ม ให้กรอกเฉพาะน้ำหนักที่เพิ่ม
5. ติ๊กเซตสำเร็จแล้วเริ่มพักอัตโนมัติ ปัดซ้ายเพื่อเผยปุ่มลบ และมี “เลิกทำ”

## ขอบเขตเอกสาร

สเปกผลิตภัณฑ์สรุปจากการออกแบบในแชต ส่วนรายละเอียดฐานข้อมูลและแนวทางทางเทคนิคเป็นข้อเสนอสำหรับเริ่มพัฒนา ยังไม่ได้สร้างแอป Flutter หรือฐานข้อมูลจริง

วันที่ตัวอย่าง รายการท่า และข้อจำกัดจำนวนรายการใน Wireframe เป็นข้อมูลสาธิต ไม่ใช่ข้อจำกัดถาวรของแอป เวอร์ชันจริงต้องใช้วันที่และข้อมูลที่ผู้ใช้เลือกได้

## งานถัดไป

1. ตรวจ Flutter SDK และเครื่องมือสำหรับ Android/iOS
2. สร้างโปรเจกต์ ธีมดำ และส่วน UI ที่ใช้ร่วมกัน โดยเฉพาะแถวเซต
3. ทำโมเดลและการเก็บข้อมูลในเครื่องตามเอกสาร
4. เชื่อมเส้นทางหลักให้ครบ แล้วทดสอบการเก็บข้อมูล การจับเวลาพัก และการแจ้งเตือนบนทั้งสองระบบ
